# rofd 基础阅读体验设计

状态：用户已确认，2026-09-08 完成实现与本机验证。

## 目标与范围

让现有 Qt/QML 原型满足日常 OFD 阅读：打开文档、连续滚动、页面跳转、缩放、全文搜索及结果定位。保留 Rust 核心库、Cairo 渲染、Qt/QML 界面的分层，不把 Qt 依赖引入核心库。本次不包含编辑、批注、打印和 OCR。

## 方案选择

1. 推荐：连续滚动为默认，配合可收起的页面缩略图/搜索侧栏。适合长文阅读，功能入口清晰；需要可见页面加载与受限缓存。
2. 单页模式增加工具栏：改动较小，但滚动到页尾不能自然接着阅读。
3. 多标签与完整菜单式阅读器：扩展空间大，但超出当前基础阅读需求。

## 界面

默认窗口 1120 × 800，最小 800 × 560。使用系统中文字体、浅色工具栏、浅灰阅读画布、白色纸张和轻微阴影。蓝色只用于选中与主操作，统一线性图标，常用按钮带悬停提示和键盘焦点。

顶部单行工具栏从左到右为：打开、文件名、侧栏开关、上一页/页码输入/总页数/下一页、缩小/缩放比例/放大、适合宽度/整页、搜索。窄窗口时文件名优先省略，适配操作收进菜单。

左侧约 216 像素，提供“页面”和“搜索”两种内容。页面缩略图带页码，当前页有蓝色边框；搜索显示输入框、匹配数、上一条/下一条和带页码的片段列表。侧栏可完全收起。

主区域默认垂直连续滚动，页面居中，页间留 24 像素间隙；放大后支持横向滚动。底部轻量状态栏显示当前页、总页数、缩放比例与加载状态。空白页显示打开文档入口与 Ctrl+O 提示。

## 交互

- 缩放范围 25%–400%，预设比例与自定义百分比，支持 Ctrl+加号/减号和 Ctrl+滚轮。100% 按 96 DPI 的逻辑尺寸显示，实际渲染考虑屏幕像素比。缩放保留当前阅读位置，适合宽度和整页模式随窗口变化重算。
- 页面输入以 1 为起点，Enter 跳转；非法输入恢复当前页。首尾按钮正确禁用。滚动时以视口中部所在页面更新当前页。PageUp/PageDown 滚动一个视口，Ctrl+Home/End 到首尾页。
- Ctrl+F 展开搜索并聚焦；输入防抖后检索，Enter/Shift+Enter 切换匹配，Esc 关闭搜索。点击结果跳到目标页和文字区域，高亮全部当前页匹配，并区分活动匹配。
- 搜索中文及英文文字，默认英文不区分大小写；按页和源文本顺序排列。支持同一文字对象内跨 TextCode 匹配，不推断不同文字对象之间的自然阅读顺序。第一版以命中文字对象的边界框高亮，明确避免承诺字形级精确高亮。纯扫描件提示“未检测到可搜索文字”。
- 打开失败显示可读错误并保留原文档；页面渲染失败在该页显示重试入口。更换文件重置搜索和阅读位置，旧任务结果不得覆盖新文档。

## 实现边界

- 在阅读器内独立组织文档会话、页面模型、渲染调度和搜索索引模块。尽量复用 rofd-core 的 Page、Layer、TextObject 和 TextCode 公共接口。
- QML 拆分工具栏、导航侧栏、页面视图、搜索面板和空状态，使用 Qt Quick Controls 的按钮、输入框和滚动条支持键盘与无障碍。
- 使用后台工作队列处理页面解析、渲染和搜索；Qt 对象只在 GUI 线程更新。请求带文档代次标识，忽略过期任务。
- 页面视图只请求可见页和邻近页。渲染缓存以文档、页码和缩放级别为键，内存预算 128 MiB；超大页面限制像素数，必要时降低栅格清晰度并提示。缩放过程先复用旧图，停止交互后刷新清晰图。
- 缩略图独立低分辨率加载，避免一次渲染全部页面。页面图像使用有所有权的 PNG data URI 传递，不再生成临时文件；缓存淘汰不影响正在加载的图片。
- 搜索按页在后台执行，复用核心库已解析的页面，限制结果数量为 1000 条，达到限制明确显示“至少 1000 条”。个别页面解析失败时提示搜索不完整，不将其当作无匹配。

## 验收

- 自动测试覆盖页面越界、缩放限制、Unicode 搜索、跨 run 匹配、无文本、结果循环、旧文档任务丢弃和缓存限制。
- 使用真实 OFD 验证打开、连续滚动、页码同步、跳页、缩放、窗口调整、搜索定位和错误提示；使用多页测试文档覆盖不同页面尺寸和搜索命中。
- 检查默认窗口与最小窗口的实际截图，无遮挡、布局跳动或 QML 运行警告。
- 执行 cargo fmt --all -- --check、核心库及受影响包测试、核心库和 Qt 阅读器 Clippy 检查，并实际构建运行 qt-reader。

## 实现细化

- 连续适宽按文档最宽页面计算，避免混合横竖页面时自动裁切或滚动触发缩放跳变；整页模式按目标页计算。
- 首次打开仅扫描页面尺寸，新增 `Document::page_size()` 不填充图形内容缓存。文本检索采用逐页扫描，尚未持久化独立全文索引；首次搜索仍需解析各页。
- 后台发布候选文档，界面确认后才激活；打开失败保留已接受文档。离屏与旧缩放任务使用请求编号取消；已进入 Cairo 的单页绘制会完成，但过期结果被丢弃。
- Qt Quick Basic 控件配合统一颜色和线性图标，避免系统控件主题导致输入框或加载动画异常。
- 验证记录与快捷键见 `docs/reader.md`；实际截图在 `docs/screenshots/`。
