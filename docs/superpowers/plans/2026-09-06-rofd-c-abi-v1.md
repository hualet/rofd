# rofd C ABI v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a versioned C ABI that opens OFD files, owns documents/pages/renderers safely, renders pages into caller-owned Cairo contexts, and exposes fatal errors plus non-fatal diagnostics to a future Qt reader.

**Architecture:** Add a single unsafe boundary crate, `rofd-ffi`, above the safe `rofd-core` and `rofd-render` crates. Keep the hand-written C header canonical, represent all state with opaque owned handles, convert versioned `#[repr(C)]` input records into safe Rust values before calling the existing libraries, and catch unwinds at every exported function. Verify the boundary with Rust tests, independently compiled C/C++ consumers, and a defined-symbol snapshot.

**Tech Stack:** Rust 2021, `rofd-core`, `rofd-render`, `cairo-rs`/Cairo C API, C11, C++17, Cargo, `cc`, `c++`, `pkg-config`, and `nm`.
